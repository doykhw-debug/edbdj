# SBS 라디오 참여 도우미 — 철파엠 1차 조사·개발 명세

조사일: 2026-10-02 (Asia/Seoul)
첫 대상: 김영철의 파워FM
목표: 고릴라 단답형 퀴즈 참여 + 본인의 실제 경험을 바탕으로 한 코너게시판 사연 작성·제출 자동화
상태: 기획·공개 페이지 조사. 실제 로그인, 방송 수집, 입력창 조작, 게시 및 응모 테스트는 하지 않음.

## 1. 이번 조사에서 확인한 것과 확인하지 못한 것

공식 페이지 제목·검색 노출 및 주소로 코너별 게시판 경로를 확인했다. 일반 텍스트 조회에서는 프로그램 페이지 본문 대부분이 반환되지 않았다. 별도 코드 실행 환경의 SBS 접속도 DNS 해석 실패로 진행되지 않았다. 이는 조사 환경의 한계이며 SBS의 차단·장애라는 증거가 아니다.

확인: 프로그램 메인, 아래 게시판 경로, 일부 글쓰기 페이지 경로, 고릴라 공감로그의 무료 참여 안내, 고릴라 회원가입·개인정보 관련 안내, 웹/Windows 화면 자동화 도구의 일반 기능.

미확인: 각 코너의 현재 접수 여부, 최신 모집 공지·글자 제한·양식·마감·상품, AI 보조 작성 및 자동 제출 허용 여부, 중복 응모 규칙, 로그인 후 입력 요소, 자동 입력·등록 성공 여부, 당첨 결과 확인 방식, 해당 퀴즈의 고릴라 응모 인정 여부.

게시판 경로가 존재한다고 현재 모집 중이라고 판단하지 않는다. 웹 글쓰기 화면의 경로는 서버 등록 API가 아니다.

## 3. 시스템 설계 제안

### A. 고릴라 퀴즈

정해진 구간 수신 → 문제·보기·마감·응모 채널 추출 → 단답형 정답 후보 → 검증 → 고릴라 입력 → 조건부 제출 → 게시 결과 확인.

- 대상 채널·프로그램·방송 날짜를 구분한다. 재방송/정답 발표를 새 문제로 오인하지 않는다.
- 문제나 보기, 마감 또는 고릴라 응모 인정 여부가 불분명하면 자동 제출을 보류한다.
- 같은 문제를 재안내해도 한 번만 처리한다. 중복 키에 계정·프로그램·방송일·문제 식별값을 포함한다.
- 실행 시간의 여유 구간은 실측 후 정한다. 임의 출제 시각을 확정하지 않는다.
- 실제 게시 확인이 실패했을 때는 결과 불명 상태로 저장하고 무조건 다시 보내지 않는다.

### B. 홈페이지 사연

코너 조건 등록 → 사용자가 승인한 실제 경험 선택 → 맞춤 제목·본문 생성 → 사실·개인정보·중복 검사 → 검토/승인 → 웹 입력 → 조건부 제출 → 글 주소·접수 결과 보관.

- 첫 대상은 사연과 신청곡 한 곳으로 제한한다.
- 게시판의 존재와 현재 사연 모집 여부를 별도 필드로 관리한다.
- 모집 공지·마감·필수 항목을 확인하지 못하면 제출 대기 상태로 둔다.
- 본문을 여러 개 생성하는 것과 여러 곳에 실제 제출하는 것은 별개로 취급한다.
- 같은 사건을 문장만 바꿔 여러 프로그램에 보내지 않도록 경험 단위 이력도 확인한다.
- 사용자가 확인한 게시물만 제출 대상으로 삼고, 무검토 자동 제출은 규칙과 사용자 권한을 확인한 범위에만 활성화한다.
- 현 시점에서 실제 게시에 대한 개별 실행 명령을 받은 것으로 취급하지 않는다.

### C. 공통 관리

필요한 화면: 코너 목록 / 실제 경험 저장소 / 퀴즈·원고 검토함 / 제출 이력·당첨 확인 / 설정·일괄 중지.

핵심 구분:
- 글 등록 성공 ≠ 퀴즈 정답 인정 ≠ 사연 채택 ≠ 당첨 ≠ 상품 수령.
- 각 상태를 별도로 저장한다. 다른 청취자 댓글을 공식 당첨 발표로 간주하지 않는다.
- 코너별 공지 변경을 확인할 수 있는 경우 변경 내용을 표시하고 재검토 전 제출을 멈춘다.

한 PC에서 웹 게시와 고릴라 화면 조작이 겹치지 않도록 입력 작업을 직렬화한다. 향후 파워FM/러브FM 동시 참여 시 채널과 음성 수집 경로를 각각 검증한다.

## 4. 기술 후보와 검증 순서

웹 게시판: Python + Playwright 후보. 이는 웹 입력·버튼 조작을 지원하지만 SBS 글쓰기 창의 실제 구조와 허용 조건은 미검증.
PC 고릴라: Windows 화면 요소 자동화 후보. 고릴라의 입력창·등록 버튼을 실제로 식별할 수 있는지 미검증.
음성 수집·인식: 독립 모듈. 접근이 허용된 방송 소스를 사용하고 이용 범위를 확인한다.
저장소: 로컬 데이터베이스에 본인의 경험·승인된 초안·제출 결과를 저장한다.
AI: 유료 API는 별도 동의 전 연결하지 않는다. 구독형 개발 도구와 운영 API 비용을 혼동하지 않는다.

1) 읽기 전용 점검: 공지, 현재 접수 여부, 로그인 방법, 필수 항목, 글자 제한, 공개 범위, CAPTCHA 유무, 이용 조건 확인.
2) 로컬 모의 화면 테스트: 실제 사이트에 글을 남기지 않는다.
3) 사용자가 직접 로그인한 화면에서 입력만 시험. 임시저장도 서버 변경일 수 있으므로 무단 실행하지 않는다.
4) 현재 참여 조건이 확인된 실제 원고/정답 1건을 사용자 승인 후 제출하고 결과 확인.
5) 정확도·오등록·중복·지연·세션 만료를 검증한 뒤 허용된 대상에 한해 자동 실행.

로그인·CAPTCHA·추가 인증은 사용자가 처리한다. 우회하지 않는다. 비밀번호, 쿠키, 세션 토큰을 채팅·GitHub·평문 로그에 저장하지 않는다. 세션 재사용은 허용된 범위에서 사용자 PC에 제한하고 세션 만료 시 중지한다.

## 5. 사연 작성 원칙

사건·인물관계·결과는 실제 경험을 기준으로 한다. 창작은 문장, 구성, 리듬, 비유와 전달 방식에 적용한다. 기억이 불확실한 대사는 직접 인용으로 확정하지 않는다. 새로 보탠 사건은 사용자 확인 전 제출하지 않는다.

질병·사고·사망·경제적 곤란·가족관계 등을 당첨을 위해 만들어 넣지 않는다. 회사·거래처·아이의 이름과 연락처는 기본적으로 익명 처리한다. 모집 공지가 창작물이나 AI 보조 작성에 제한을 두면 그 조건을 적용한다.

사용자 배경으로 이미 알려진 소재 범주: 약국 관련 영업, 영상 편집·제작 부업, 배우자와 아이가 있는 가족 일상, 영어 공부 관심·배우자의 전화영어 경험. 이 배경만으로 구체적 사건을 만들어 실화로 확정하지 않는다. 과거 고양이 등원 영상 등 제작용 설정도 실제 가족 경험과 구분한다.

## 7. 규칙·선물 확인

고릴라 무료 참여와 자동 참여 허용은 구분한다. 게시판의 존재도 경품 지급을 뜻하지 않는다. 각 이벤트의 참여 조건·선정 방식·마감·선물 수령 절차를 별도로 확인한다.

본문을 확인한 SBS 약관 페이지의 시행일은 2024-09-30이다. 해당 문서는 도배, 운영 방해, 개인정보 침해 등과 관련한 제한을 포함한다. 현재 고객센터의 최신 약관 링크는 https://www.sbs.co.kr/terms/index.html 로 이어졌지만 본문은 이번 환경에서 확인하지 못했다. 따라서 최신 규정 전체 확인이나 자동 참여에 대한 SBS의 허락을 받았다고 표시하면 안 된다.

고릴라 개인정보 처리방침은 공감로그 작성의 회원가입 기반 제공, 방송/이벤트 참여 확인과 상품 발송을 설명한다. 당첨 연락처·배송정보는 필요한 때 공식 비공개 절차로 사용자가 직접 제공하고 공개 사연 본문에 넣지 않는다.

다른 청취자 사연을 대량 수집해 모방·재작성하는 기능은 만들지 않는다. 본인의 경험 저장소와 필요한 코너 조건만 최소한으로 관리하고 수집·음성 처리의 허용 범위를 별도로 확인한다.
