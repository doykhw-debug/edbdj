가져오기 특징·경험 · 인물 관계도 · 사연 로그

파일 종류는 내용을 보고 알아서 고릅니다.

  • 특징·경험 (.json) — 기본 정보와 실제 경험.
  • 인물 관계도 (character-map.md) — 인물 카드와 실제 사건(연표)을 인물에 넣습니다. 〔사연〕 가상 사건은 넣지 않습니다. 다시 넣으면 고친 내용으로 바뀌고, 직접 정한 호칭·가까움·메모는 그대로입니다.
  • 사연 로그 (.jsonl) — 사연 보관함에 넣습니다. 원본 사연을 각색한 가상 사연은 읽기용이며 보내지 않습니다.
  • 가져온 경험은 '실제로 있었던 일' 확인이 꺼진 상태로 들어갑니다. 실제 경험 화면에서 하나씩 읽고 체크해야 사연·원고에 쓰입니다.
  • 같은 내용의 경험은 다시 넣지 않습니다.
  • 실명·회사명·연락처는 파일에 넣지 말고, 기본 정보의 '본문에 나오면 안 되는 단어'에 직접 적으세요.

파일 형식

필요한 항목만 있으면 됩니다. 경험은 'story'(있었던 일)만 꼭 있으면 됩니다.
