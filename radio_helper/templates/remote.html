비밀번호는 원본을 저장하지 않고 암호화한 값(해시)만 이 PC 데이터 폴더에 둡니다. 5번 틀리면 15분 잠깁니다. 비밀번호를 바꾸면 밖에서 로그인해 둔 화면은 모두 로그아웃됩니다. 비밀번호는 PC 앞에서만 정하고 바꿀 수 있습니다.

처음 한 번 설정 (Cloudflare 에서 5분)
  1. Cloudflare 대시보드 → Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared → 이름 radio-helper.
  2. 환경을 Windows 로 고르면 나오는 명령(cloudflared.exe service install …)을 이 PC의 관리자 명령 프롬프트에 그대로 붙여 넣습니다 (cloudflared 설치 파일도 그 화면에서 받음). 이 명령 안의 긴 토큰은 비밀번호와 같으니 채팅·메신저·GitHub 에 올리지 마세요. PC를 켜면 터널이 저절로 켜집니다.
  3. Public Hostname: Subdomain radio, Domain haetsallab.com, Service HTTP · localhost:{{ r.tunnel_port }} 로 저장합니다.
  4. (권장) Zero Trust → Access → Applications → Add → Self-hosted 에서 {{ r.domain }} 를 넣고 정책을 Emails — 내 이메일 로 정하면, 이 도우미 비밀번호 앞에 Cloudflare 가 이메일 인증을 한 번 더 받습니다.
  5. 위 밖에서 연결되는지 확인을 눌러 '연결됨'이 나오면 끝입니다.
