문자로 보내는 원리

라디오 문자(#1077 등)는 내 휴대폰 번호로 보내야 해서, PC에 USB로 연결한 휴대폰의 기본 문자 앱을 이 프로그램이 대신 눌러 보냅니다. 보내기 직전에 작성 화면의 받는 번호가 '#' 까지 맞는지 확인하고, 다르면 보내지 않습니다.

요금: 라디오 문자는 건당 약 50원(긴 글은 더)이 휴대폰 요금에 붙습니다. 비용 상한은 두지 않았습니다. 오늘 문자로 보낸 글 {{ today.count }}건 (약 {{ '{:,}'.format(today.won) }}원). 지금 보내는 방법: {{ '문자' if route == 'sms' else '앱 채팅' }} (청취 화면에서 바꿈)

처음 한 번 준비

  1. 휴대폰 개발자 옵션 켜기 — 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 누릅니다.
  2. USB 디버깅 켜기 — 설정 → 개발자 옵션 → USB 디버깅 켜기. 같은 화면의 '충전 중 화면 켜짐 유지'도 켜 두면 청취 중에 화면이 잠기지 않습니다.
  3. PC에 adb 두기 — Google 공식 SDK Platform-Tools for Windows를 내려받아 압축을 풀고, 나온 platform-tools 폴더를 이 프로그램 폴더(start_windows.bat 이 있는 곳)에 넣습니다. {% if adb %}찾음 {{ adb }}{% else %}아직 없음{% endif %}
  4. USB로 연결 — 휴대폰에 'USB 디버깅을 허용하시겠습니까?'가 뜨면 '이 컴퓨터에서 항상 허용'을 체크하고 허용합니다.
  5. 연결 점검 → 시험 문자 보내기. 휴대폰 화면 잠금은 풀어 두세요.
